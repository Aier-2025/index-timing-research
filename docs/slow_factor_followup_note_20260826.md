# 慢因子后续研究记录

日期：2026-08-26

## 当前状态

慢因子复杂调整模型暂缓，不纳入当前指数择时主结论，也不作为新的样本外结果发布。

## 已完成的探索

- 已按响应型、 中频、持久/滞后持久和慢发布对因子合同分组。
- 已完成一次频率分组历史重放诊断：技术、55 快因子、快加中频、快加慢因子、慢变量变换和快慢融合。
- 初步观察到：慢因子直接与快因子拼接会抬高部分开发期指标，但历史重放普遍回落；直接平权输入存在时间尺度错配、特征数量不平衡和持久变量冗余问题。
- 已设计但暂停运行快主模型加慢独立调整模型，包括并行仓位上限、连续缩放、状态门控、串行残差调整，以及不同快/慢期限和 fold 长度组合。

## 下一步恢复顺序

1. 先完成慢因子统计审计，不训练复杂交易模型。
2. 对 20 日和 60 日标签分别计算字段级 IC、RankIC、分位条件收益、年度符号稳定性、滚动稳定性、更新频率、自相关和冗余。
3. 判断慢因子主要是方向预测、状态识别还是风险控制信息。
4. 只有统计证据足够稳定时，才建立低复杂度慢模型；优先使用少量聚合变量或单一风险上限，不使用大规模慢因子模型。
5. 期限和 fold 长度必须预声明并在滚动训练折内选择，不能使用历史重放区间反向调参。

## 结果解释边界

当前所有慢因子开发结果均属于开发期诊断或已观察历史重放，不得称为新的 OOS 证据。当前主策略仍以快因子/项目现有滚动候选为准。
