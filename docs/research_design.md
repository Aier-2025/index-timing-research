# 五指数日频择时研究设计

## 研究对象

| 指数 | 代码 | 数据源 | 有效行情起点 |
| --- | --- | --- | --- |
| 中证500 | 000905 | JoinQuant | 2007-01-15 |
| 创业板指 | 399006 | JoinQuant | 2010-06-01 |
| 中证1000 | 000852 | JoinQuant | 2014-10-17 |
| 科创50 | 000688 | JoinQuant | 2020-07-23 |
| 中证2000 | 932000 | TonglianData | 2023-08-11 |

指数使用原始价格指数点位，不做前复权，不计分红。指数基日或发布日期不等于可回测行情起点，实际起点以首个有效收盘价为准。

## 时间轴与因子可得性

- 总体时间轴采用五个指数有效交易日集合的并集。
- 每个指数只在自身有效行情区间内计算标签和策略收益；上市前日期保留缺失，不做前向填充。
- 2015-01-01 之前不计算、不填充宏观和市场情绪类因子。
- 2015 年后宏观、情绪、资金和外部字段必须按字段的 `availability_lag_days` 后移；缺少可靠发布时间的字段暂不准入。
- 价格技术因子只使用信号日及此前的 OHLC 数据；信号日收盘后生成，下一交易日开盘执行。

## 数据与研究层

1. `F:/data/index_timing_raw/` 保存供应商原始文件、下载 manifest 和 SHA256。
2. 项目脚本标准化五指数字段为 `trade_date, index_code, open, high, low, close, volume, money, source`。
3. 首期因子分为价格技术类、跨指数相对强弱类和 2015 年后市场状态类。指数 `volume/money` 为空或口径不明时不作为成交量因子。
4. 慢专家单独测试 20 日、60 日和六期限 `1/3/5/10/20/60` 组合；短历史指数只使用其可支持的训练窗口并报告样本量，不强行复制长历史参数。

## 回测与防未来函数

- 标签使用从下一交易日开始的开盘到开盘收益，或在开盘缺失时明确降级为收盘到收盘收益。
- 训练样本的未来标签必须完全成熟后才能进入训练集。
- 模型采用滚动 walk-forward。开发期选择特征、期限、模型和仓位映射；冻结 OOS 只评估一次，不反哺参数。
- 所有滚动统计、缺失填补、截尾、标准化和分位点均只能使用训练窗口。
- 输出未来函数审计：字段滞后、标签成熟日、执行日、训练截止日、特征 first-valid date。

## 评估输出

每个指数和策略版本输出年化收益、夏普、最大回撤、Calmar、相对买入持有超额、换手/仓位变化、成本敏感性、年度分解和样本覆盖。研究阶段只报告实际计算结果，不把开发期结果称为样本外有效性。

## 仓库边界

GitHub 仓库只提交代码、配置、文档、测试、小型样例和数据 manifest。原始行情、通联凭证、JoinQuant cookie、模型大文件和本地缓存留在 `F:/data/` 或用户私有目录，不提交到 GitHub。
