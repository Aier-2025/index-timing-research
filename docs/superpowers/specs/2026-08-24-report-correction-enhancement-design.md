# 五指数报告修订与增强设计

## 目标

修复中证500/创业板指早期净值图的缺失传播问题，统一超额收益定义，延长中证2000训练集至2025-12-31并从2026-01-01开始OOS，同时提升报告的信息密度和可审计性。

## 数据与指标

- 原始指数序列按每个指数自己的有效收盘区间计算，绘图和收益计算不对指数成立前的空值做前向填充。
- 主动收益定义为逐日 `strategy_return - benchmark_return`；累计超额净值为主动收益序列的 `cumprod(1 + active_return)`，年化超额与超额夏普均基于该序列。
- 保留策略净值、基准净值、主动收益、成本、换手等逐日字段，报告明确区分“策略净值”“基准净值”“累计超额净值”。
- 中证2000配置改为训练/开发期截至2025-12-31，OOS起点2026-01-01，保持滚动训练、重训周期和成本模型不变。

## 报告结构与图表

- 顶部总览：研究边界、数据审计摘要、五指数候选表。
- 因子与模型章节：解释量价/趋势、风险/波动、流动性/宽度、宏观状态四类因子；解释滚动训练、滞后、Ridge、五档仓位和规则策略。
- 图表全部以内嵌高分辨率 PNG 大图交付，避免外部路径依赖。
- 新增 OOS 指标热力图、年度收益箱线图、主动收益分布箱线图、逐年超额热力图；保留净值/回撤、持仓、年度分解和成本图。
- 500/创业板图表对无效日期使用掩码，不显示水平线假象，并在图中标注首个有效日期。

## 替代微盘指数

优先检查国证2000（399303）等更早发布、成分数具有代表性且本地数据源可验证的指数。若数据源可用，下载完整日线并单独生成审计清单；不在未经同口径回测前替换中证2000。
