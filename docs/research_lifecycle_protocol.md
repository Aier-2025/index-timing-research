# 训练集与回测集纪律

## 当前状态

截至 2026-08-24，当前研究统一划分为训练集和回测集。滚动模型结果按完整回测区间拼接后评价。

## 三阶段

### 训练集

训练集用于拟合模型、生成候选特征和确定可行的特征合同。允许改变模型、因子、期限、仓位和成本假设。

### 回测集

回测集用于比较候选策略和评价冻结方案。当前项目的五指数 worker 结果属于这一阶段，输出在：

`F:/data/index_timing_raw/index_oos_workers/<index_code>/`

### 回测纪律

回测指标至少包括：

- 完整拼接回测区间的年化收益和基准年化收益；
- 年化超额收益；
- 超额夏普；
- 最大回撤、换手和成本后结果；
- 回测区间起止日期、有效交易日数、缺口和数据版本。

回测结果不得反向用于调整同一策略版本。如果回测没有超额，当前策略判定未通过；若要改策略，必须新建训练集和回测集，并重新评价完整回测区间。

## 交易成本

指数点位不是直接可成交资产，项目使用统一执行成本代理：单边手续费 `3 bp`、单边滑点 `5 bp`，合计单边 `8 bp`。成本按 `abs(position_change)` 计提，所有报告的策略收益和超额指标默认是成本后结果；账本同时保留 `commission`、`slippage`、`total_cost` 和 `gross_strategy_return`。
